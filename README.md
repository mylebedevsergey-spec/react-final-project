# Сад и Огород на React и TypeScript

Финальный проект курса. Каталог садовых товаров с входом по JWT. Фронтенд на Vite, React и TypeScript,
бэкенд на FastAPI, данные в SQLite.

## Что сделано по требованиям

Проект собран на Vite с шаблоном React и TypeScript, запускается через npm run dev, сборка проходит
без ошибок типов.

Маршрутов пять: каталог, карточка товара с динамическим параметром, вход, избранное и страница 404.
Избранное закрыто компонентом PrivateRoute, который проверяет токен при прямом заходе по адресу,
а не только скрывает ссылку в меню. После входа возвращает на ту страницу, откуда выкинуло.

Запросы идут через axios-клиент с baseURL и двумя интерцепторами. Первый подставляет Bearer из
localStorage, второй ловит 401, чистит токен и разлогинивает. Интерфейсы в types.ts повторяют
Pydantic-схемы бэкенда, any в коде нет.

Состояние каждого запроса описано объединением loading, error и data, для этого есть хук useRequest.
На страницах видны все три состояния, при ошибке есть кнопка повторить.

В Zustand два хранилища. Одно для избранного, оно не связано с авторизацией и сохраняется
в localStorage через persist. Второе для пользователя и статуса входа.

Форма входа проверяет почту и длину пароля, ошибки показывает после того, как поле тронули.
Выход очищает токен.

Стили на CSS Modules, у каждого компонента и страницы свой файл, общие переменные и шрифты
в styles/global.css. Tailwind не смешивал.

## Структура

```
api/                 бэкенд
  main.py            эндпоинты, JWT, SQLite, PBKDF2
  requirements.txt
app/                 фронтенд
  src/api/           axios-клиент и запросы
  src/hooks/         useRequest
  src/store/         authStore, favoritesStore
  src/components/    Layout, ItemCard, PrivateRoute, Loader, ErrorState
  src/pages/         Catalog, Item, Login, Favorites, NotFound
  src/styles/        общие стили
```

## Запуск

Бэкенд:

```
cd api
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

Фронтенд. В dev настроен прокси с /api на 8000, отдельно менять ничего не нужно:

```
cd app
npm install
npm run dev
npm run build
```

Демо-доступ: student@example.com и password123.

## API

POST /auth/login выдаёт JWT на час, GET /auth/me отдаёт профиль по токену, GET /items принимает
параметры category и search, GET /items/{id} возвращает товар или 404, POST /items создаёт товар
и требует токен.

## Что проверял

Сборка проходит без ошибок типов. Каталог получает десять товаров с бэкенда. Прямой переход
на /favorites без токена даёт редирект на вход, после входа возвращает на избранное. /items/4
открывает «Монстеру». Несуществующий адрес показывает 404. Неверный пароль возвращает 401
и сообщение в форме.
